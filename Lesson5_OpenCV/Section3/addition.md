# 补充信息

## 1. Vec4i
### `cv::Vec4i` 的本质
`cv::Vec4i` 是 OpenCV 中定义的 **4维整型向量**，本质是一个包含4个`int`元素的模板类：
```cpp
typedef Vec<int, 4> Vec4i;  // 等价于 int[4]
```

### 在轮廓检测中的用途
当使用 `cv::findContours()` 的 `cv::RETR_TREE` 或 `cv::RETR_EXTERNAL` 等模式时，`hierarchy` 参数的类型就是 `std::vector<cv::Vec4i>`。每个 `Vec4i` 存储一个轮廓的**层次关系信息**：

```cpp
std::vector<cv::Vec4i> hierarchy;
cv::findContours(..., contours, hierarchy, cv::RETR_TREE, ...);
```

#### `Vec4i` 的四个元素含义（对于第i个轮廓）：
| 索引 | 字段名（假设） | 含义                                                                 |
|------|----------------|----------------------------------------------------------------------|
| 0    | `next`         | 同级下一个轮廓的索引（-1表示无）                                     |
| 1    | `prev`         | 同级上一个轮廓的索引（-1表示无）                                     |
| 2    | `first_child`  | 第一个子轮廓的索引（-1表示无）                                       |
| 3    | `parent`       | 父轮廓的索引（-1表示无，如最外层轮廓）                               |


### 不同检索模式下的 `hierarchy` 差异
| 检索模式               | 典型 hierarchy 值含义                     |
|------------------------|------------------------------------------|
| `cv::RETR_EXTERNAL`     | 只检测最外层轮廓，所有`parent=-1`         |
| `cv::RETR_LIST`         | 简单列表，所有`parent=-1`（无层次关系）   |
| `cv::RETR_TREE`         | 完整树结构，明确父子关系                  |


### 与其他数据结构的对比
| 类型               | 元素数量 | 元素类型 | 典型用途                     |
|--------------------|----------|----------|------------------------------|
| `cv::Vec2i`        | 2        | int      | 存储点坐标(x,y)              |
| `cv::Vec3i`        | 3        | int      | RGB像素值                    |
| `cv::Vec4i`        | 4        | int      | 轮廓层次关系                 |
| `std::vector<int>` | 动态     | int      | 通用场景                     |
